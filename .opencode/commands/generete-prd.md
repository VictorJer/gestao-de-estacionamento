description: Gerar um PRD completo a partir de um prompt inicial
---

Carregue a skill `generete-prd` com a ferramenta `skill` e siga suas instruções para criar o documento de requisitos de produto.

Prompt inicial do usuário: $ARGUMENTS

Se o argumento estiver vazio, peça ao usuário uma descrição do produto ou funcionalidade antes de prosseguir.
